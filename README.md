# FinConnect

Repositório dedicado ao desenvolvimento da atividade da Fase 4 relacionada ao projeto Fintech.

## 📋 Descrição

O **FinConnect** é uma aplicação web moderna de gerenciamento financeiro pessoal. Essa é a tela inicial, desenvolvida como atividade da Fase 4 do programa, e oferece uma interface intuitiva e responsiva para controlar receitas, despesas, orçamentos e caixinhas de poupança.

### Funcionalidades (Ainda não aplicadas, apenas a camada visual)

- 💰 **Resumo Financeiro**: Visualização rápida do saldo atual, receitas e despesas
- 📊 **Caixinhas de Poupança**: Organização das economias em categorias personalizadas
- 📈 **Orçamento**: Definição e acompanhamento de limites de gastos por categoria
- 💳 **Transações**: Histórico completo de movimentações financeiras
- 📅 **Contas Recorrentes**: Gerenciamento de contas pagas, não pagas e próximas a vencer

## 🎨 Tecnologias

- **HTML5** - Estrutura semântica
- **CSS3** - Estilização responsiva e moderna
- **Bootstrap 5.3** - Framework CSS para componentes e grid

## 📱 Design Responsivo

A aplicação foi desenvolvida com abordagem mobile-first, adaptando-se perfeitamente a:

- Dispositivos móveis (até 992px)
- Tablets e desktops (992px - 1300px)
- Telas grandes (acima de 1300px)

## 🚀 Como Utilizar

1. Clone ou baixe o repositório
2. Abra o arquivo `index.html` em seu navegador
3. Explore as diferentes seções através da navegação lateral
